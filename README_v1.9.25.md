# SAHOVERSE v1.9.25 — 扇形手札の細部調整

基準: v1.9.24 / 2026年11月20日

## 今回の変更（UIのみ）

- 手札が横にあふれる場合、現在見えている手札範囲（例：`1–4 / 14`）を送りボタン横へ表示。
- 左右それぞれの終端では、対応する送りボタンを自動的に無効化。スクロール、リサイズ、ゲームの再描画後にも更新。
- 端で一部が隠れている手札を選択した場合、横方向だけを必要最小限スクロール。縦方向のページ位置は動かさない。
- PC/iPadのキーボードでも、手札にフォーカスした状態で左右矢印、Home、Endキーでカード間のフォーカス移動が可能。Enter/Spaceで従来どおり選択できる。
- スクロール位置を復元してから送りボタンの有効/無効を判定。手札が増減した後も状態を更新。
- 変更通知は `requestAnimationFrame` で1フレームに最大1回。全盤面を描き直さず、2つのボタンと短い表示文字だけを更新。
- 扇形の角度・重なり・カード作成・死者蘇生・効果解決・戦闘・Firebase処理は変更していません。

## GitHubアップロード

1. v1.9.24反映済みの場合は `SAHOVERSE_v1.9.25_PATCH_ONLY.zip` を使用し、含まれる3ファイル（`app.js`, `visual-upgrade.css`, `index.html`）をGitHubリポジトリ最上位へ上書きアップロード。
2. v1.9.24より前なら `SAHOVERSE_v1.9.25_FULL_INTEGRATED.zip` を使用し、アプリの最上位ファイルを上書きアップロード。
3. **`firebase-config.js` と `database.rules.json` はどちらのZIPにも含まれません。リポジトリ内にある既存ファイルを削除・変更しないでください。**
4. `main` ブランチでコミット後、 `https://michisamichi.github.io/duel-craft/?v=1925` へアクセスしてGitHub Pagesの更新を確認。
