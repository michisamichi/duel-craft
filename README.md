# SAHOVERSE v1.9.6 — 効果エディター大幅拡張

## 新機能

- **効果処理38種類**を、使う頻度を考慮して並べ替えました。
- 自由設定では、発動条件・処理・対象・整数値を選べます。数値はプルダウンではなく直接入力です。
- カードを引く、回復する、ダメージを受ける等のプレイヤー対象効果は、**自分と相手のどちらも指定できます**。
- モンスターや魔法・罠の破壊・除外・戻し・強化・弱体化等は、自分側・相手側を指定できます。全体対象にも対応しました。
- 装備魔法では自分／相手のモンスターを指定できます。フィールド魔法の永続攻守変化も自分・相手・双方から選択できます。
- カードの効果文・表示攻守・ターン終了処理を追加効果に合わせて更新しました。
- 以前のプリセット効果、既存カード、デッキ、ドラフト、儀式・融合、バックアップ、カード管理パスワードの動作は維持する方針です。

## 主な38種類

ドロー／モンスター・魔法・罠のサーチ／モンスター破壊・除外／LPダメージ・回復／攻守アップ・ダウン／モンスターを手札・デッキ・墓地へ送る／表示形式変更／攻守数値の指定／攻撃・起動効果の制限／コントロール変更／魔法・罠の破壊・除外・手札戻し／ランダム手札破棄・山札戻し／デッキ削り・除外・シャッフル／墓地回収・蘇生・除外・デッキ戻し／除外から回収／LP設定・半減／攻撃無効・直前のチェーン効果を無効化。

## 簡易ルール上の注意

- サーチはデッキを検索して**先に見つかった**該当種類から手札へ加えます（任意のカード名を選択する方式ではありません）。
- 墓地・除外ゾーンの効果は、**新しく置かれたカードから順番**に処理します。カード1枚ずつの手動選択はありません。
- 通常の一時的な攻守変更はターン終了時に元に戻ります。永続は場に存在する間だけ適用されます。
- 召喚時の単体対象効果は、対象が複数ある場合に最初のカードを自動選択します。
- 攻撃・効果の制限、チェーン打ち消しはカジュアル向け簡易仕様で、公式ルールの完全再現ではありません。
- 数値は整数。ドロー・手札操作等は通常1〜10枚、LP変更は最大99,999など、処理別に入力範囲があります。
- カードデータの保存・編集には従来どおりFirebase接続と管理パスワードが必要です。ルール変更は不要です。

## GitHub Pagesの更新方法

1. このZIPを解凍します。
2. `README.md`を除く**16ファイル**をGitHubリポジトリ `michisamichi/duel-craft` 直下に上書きアップロードします。
3. **Commit changes** を押します。
4. `https://michisamichi.github.io/duel-craft/?v=196` をSafariで開きます。
5. iPhone2台を使う場合は両方とも最新版へ更新してください。

**`firebase-config.js` と `database.rules.json` は今回のZIPに含んでいません。既存のファイルを削除・変更しないでください。**
