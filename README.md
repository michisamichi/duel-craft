# SAHOVERSE v1.9.4 — 自動ドロー・カード拡大表示

## 主な更新
- 対戦開始時は初期手札5枚。先攻初ターンはドローなし。
- 2ターン目以降、ターン交代と同時に次のプレイヤーが自動でカードを1枚ドローし、メイン1へ進みます。
- ドローした側の画面に、引いたカードの画像・名前・効果・攻守を大きく表示。「確認して続ける」を押すと閉じられます。
- 1台で練習時は「操作側を交代」で次のプレイヤーへ切り替えると表示されます。
- 既存のドローフェイズで中断されていたゲームも引き続き使用可能です。
- デッキ切れによる敗北判定を維持し、ターン交代時のドローを1度だけ実行します。
- v1.9.3のカード管理パスワード機能も維持しています。

## GitHub更新方法
1. ZIPを解凍します。
2. https://github.com/michisamichi/duel-craft/upload/main にアクセス。
3. README.mdを除いた16ファイルを、リポジトリの直下へ上書きアップロードします。
4. Commit changes で保存。
5. https://michisamichi.github.io/duel-craft/?v=194 を開きます。

### 削除しないファイル
- firebase-config.js（利用者のFirebase接続情報）
- database.rules.json（GitHub上のルール保存用ファイル）
Firebaseコンソール側のルール変更は不要です。

## 動作確認
Node.jsによる対戦ルールの自動テストで、初期ドローなし、自動ドロー、二重ドロー防止、デッキ切れ敗北、旧ルームのドロー処理を確認しました。全JavaScriptの構文検査に成功しています。
ブラウザ自動テストは利用環境のアクセス制限で実施できず、実際のiPhone2台での演出・通信は未検証です。
