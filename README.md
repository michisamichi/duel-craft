# SAHOVERSE v1.9.1 — 完全統合版

v1.0〜v1.9の更新ファイルを順番に統合した、iPhone向けWebアプリの全ファイル版です。

## GitHubへの反映
1. ZIPを解凍します。
2. `https://github.com/michisamichi/duel-craft/upload/main` を開きます。
3. このフォルダのうち、README.md以外の16ファイルをアップロードします（同名ファイルは上書き）。フォルダをもう1階層作らず、`index.html` がリポジトリの直下に来るようにしてください。
4. `Commit changes` で保存します。
5. 公開先 `https://michisamichi.github.io/duel-craft/?v=191` を開きます。

## 注意
- **既存の `firebase-config.js` は削除・変更しないこと。** ご自身のFirebase接続情報が入っています。
- **`database.rules.json` も今回は触れないこと。** Firebaseコンソールで有効にしたルールはそのままです。
- 通常のデッキや設定のデータは、アップロードだけでは削除されません。
- このZIPにはGitHubで動かす静的アプリの全ファイルが含まれています。Firebase接続情報そのものは含みません。
- iPhone2台でのオンライン通信・再接続は未検証です。

## 収録機能
デュエル、儀式・融合召喚、カード作成・編集、デッキ作成・共有、禁止・制限、2択・通常ドラフト、パック・パック限定戦、エフェクト、データバックアップ・復元、編集の下書き保存、再接続。

## 内部調整
過去の差分更新ではJSモジュールのクエリ番号がv130、v140、v160などに分かれていたため、今回はすべてv191に統一して重複読み込みを防ぎます。機能の仕様はv1.9から変更していません。
