# SAHOVERSE v1.9.8 — iPad対応 + オンライン対戦の参加エラー修正

## 対応内容
- iPad縦向き・横向きのカード一覧、デッキ管理、カード編集、デュエル表示を最適化（v1.9.7の全変更を収録）
- 通常対戦の部屋参加で「部屋の情報が読み込まれていません」となる不具合を修正
- 通常ドラフト／2択ドラフトの部屋参加でも、同じ初回キャッシュ問題を修正
- 部屋が本当に見つからない・満室・Firebaseの権限不足は、それぞれ区別して案内
- 既存カード・デッキ・ルール・管理パスワード・自動ドロー・エンドフェイズの手札6枚上限は維持

## 更新方法
1. ZIPを解凍し、README.mdを除く16ファイルをGitHubのリポジトリ直下にアップロードして上書きします。
   https://github.com/michisamichi/duel-craft/upload/main
2. Commit changes を押してください。
3. 2台とも同じ最新版をSafariで開きます。
   https://michisamichi.github.io/duel-craft/?v=198
4. 1台目で新しい部屋を作成し、2台目で8文字のコードを入力します。
5. 両方のiPhoneで正しく接続できるかご確認ください。

## 注意
- Firebaseの firebase-config.js と database.rules.json は削除・変更不要です（ZIPにも含めません）。
- Firebaseルールによる書き込み権限エラーの場合は、今回の修正では解消しません。表示されたエラーを確認してください。
- カード・デッキの保存データは初期化しません。
- こちらの検証ではFirebase実機2台への接続は実施していません。自動テストとiPadレスポンシブ画面テストを実施しています。
