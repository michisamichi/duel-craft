# SAHOVERSE v1.9.13 — オンライン通信専用の大規模検査・安定化更新

基準: v1.9.12。個人利用・iPhone/iPadでの2人対戦を想定し、ルール・カード・演出を変えずにオンライン時の操作整合性を改善しました。

## 改善内容

1. **通信切断中の新しい対戦操作を送らない**: Firebase の `.info/connected` と共有カードの初期同期完了を確認。通信が回復したら利用者が操作をやり直す方式にし、古い操作を無自覚にキューへ残さないようにした。
2. **同時更新によるカード取り違え防止**: 操作開始時点の部屋 `revision` とトランザクション時点の `revision` を照合。一致しない場合は中止して選び直しを案内。ドラフトのピックにも同じ確認を追加。
3. **部屋切り替え時の旧画面残留防止**: 新しい部屋の購読を始める前に前室の対戦状態を消去し、読み込み中画面を表示。解除済み購読から遅れて届いたイベントを無視する。
4. **共有カードの読み込み順序への対策**: カードライブラリの初回購読が完了するまで、オンラインの操作を保留。別端末のカスタムカードの定義を読み込む前に発動しないようにする。
5. **連打による二重部屋作成・二重入室の抑止**: 通信中の重複ボタン操作を拒否。
6. **画面が古くなったときの対象選択を解除**: 部屋の新しいリビジョンを受信したら前回の選択を解除し、カードの位置が変わってから別のカードに効果を発動しないようにする。

Firebase 設定・ルール変更なし。既存データの削除なし。v1.9.12に含まれる効果エディター・自動ドロー・手札6枚制限・儀式/融合/ドラフト・iPad表示を維持。

## 更新手順

1. ZIP を解凍。
2. https://github.com/michisamichi/duel-craft/upload/main で、README.md 以外の **17ファイルをリポジトリ直下にアップロード・上書き**。
3. Commit changes を押す。
4. 両方の端末で https://michisamichi.github.io/duel-craft/?v=1913 を開き直す。

GitHub 上にすでにある `firebase-config.js` と `database.rules.json` は **削除・変更しないでください**。

## 実機で残る確認

- Firebaseの実際の `.read` / `.write` 権限とルール検証（利用中の本番ルールを直接確認できないため）
- 2台同時に魔法・罠を発動したときの通信の再試行
- iPhone/iPadの画面ロック・Safariバックグラウンドからの復帰、接続断からの再同期
- 非常に遅い回線と複数端末からの競合

オンライン切断中の操作は、キューに残さず **接続回復後に手動で再操作**してください。同期に失敗したときは画面に表示されたエラー全文を確認してください。
